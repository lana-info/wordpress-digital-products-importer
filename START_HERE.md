# Start Here

Это проект для подготовки цифровых товаров из Excel к публикации на WordPress/WooCommerce.

1. Сначала смотри `README.md` - там описаны приложение, формат Excel и проверка.
2. Для обычной работы запускай `Start Product Import App.cmd`.
3. В Excel у товара должна быть колонка с названием и желательно колонка `product_folder` или `Папка товара`.
4. В папке товара ожидаются изображения листинга и один `.zip` файл для скачивания.
5. Если есть `TASKS.md`, бери следующую открытую задачу из него.
6. Перед завершением обязательно проверь результат локально.
