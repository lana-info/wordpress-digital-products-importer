# Short Intake

Ask only what is missing:

1. Is this a new project from the template, or work on the template itself?
2. What project name or slug should we use?
3. What is the first user flow that should work?
4. Which surfaces are active now: web, mobile, backend/API, landing, or full-stack?
5. Does the first version need auth, persistence, uploads, media, payments, or integrations?
6. Is deployment needed now?
