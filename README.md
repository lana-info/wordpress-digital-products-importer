# Anastasia

Приложение для подготовки цифровых товаров из Excel к публикации в WordPress/WooCommerce.

## Как это работает

1. В Excel одна строка = один товар.
2. В строке товара есть ссылка на локальную папку товара.
3. В папке товара лежат изображения листинга и один `.zip` архив для скачивания покупателем.
4. Приложение читает Excel, находит файлы в папках товаров и собирает CSV для импорта в WooCommerce.
5. Дополнительно создаётся `downloads_manifest.csv`, где видно, какие локальные файлы найдены.

## Как запускать как приложение

Двойной клик по файлу:

```text
Start Product Import App.cmd
```

В окне приложения нужно выбрать:

- Excel-файл с товарами;
- папку, куда сохранить результат;
- имя листа Excel, если нужен не активный лист;
- URL папки медиа, если файлы уже будут доступны на сайте по публичной ссылке.
- режим листинга: `Черновик` или `Готовый листинг`;
- нужно ли записать статус и дату обратно в Excel.

На вкладке `Настройки сайта` можно заполнить и сохранить:

- `URL сайта`;
- `WooCommerce Consumer Key`;
- `WooCommerce Consumer Secret`;
- `WordPress username`;
- `WordPress Application Password`;
- `URL папки медиа`.

Настройки сохраняются локально в `config/site_settings.json`. Этот файл добавлен в `.gitignore`, потому что там могут быть доступы к сайту.

Кнопка `Тест подключения` проверяет:

- доступность WordPress REST API;
- доступность WooCommerce REST API по `Consumer Key` и `Consumer Secret`.

После нажатия `Собрать CSV` приложение создаёт:

- `products.csv` - файл для импорта товаров в WooCommerce;
- `downloads_manifest.csv` - отчёт по найденным изображениям, ZIP и проблемам.

Если включена запись в Excel, приложение обновляет исходную таблицу:

- `status` - ставит `CSV_READY`;
- `status_date` - ставит дату и время обработки рядом со статусом;
- `publish_mode` - ставит `draft` или `publish`.

## Колонки Excel

Минимально нужна колонка с названием товара:

- `title` или `name` - название товара.

Основные колонки:

- `sku` - артикул;
- `regular_price` или `price` - цена;
- `short_description` - краткое описание;
- `description` - полное описание;
- `categories` - категории через запятую, `;` или `|`;
- `tags` - теги через запятую, `;` или `|`;
- `product_folder` - путь или ссылка на локальную папку товара;
- `download_file` - прямой путь к ZIP, если нет `product_folder`;
- `download_url` - готовая публичная ссылка на ZIP, если файл уже загружен;
- `images` - прямые пути к изображениям, если они не берутся из папки;
- `seo_title` - SEO title;
- `seo_description` - SEO description;
- `focus_keyword` - ключевая фраза.

Поддерживаются и русские заголовки вроде `Название`, `Артикул`, `Цена`, `Папка товара`, `Ссылка на папку`, `Изображения`, `Файл`.

Твой пример Excel поддерживается:

- `Title` -> название товара;
- `Description` -> описание;
- `Price` -> цена;
- `Photos` -> имена изображений внутри папки товара через `|`;
- `Digital File (ZIP)` -> ZIP-файл внутри папки товара;
- `Путь к файлам` -> папка товара;
- `Tags` -> теги;
- `status` -> статус обработки.

## Что важно про файлы

WooCommerce CSV не загружает локальные файлы с компьютера сам по себе. В CSV должны быть публичные URL изображений и ZIP.

Текущий инструмент умеет:

- найти картинки и ZIP на компьютере;
- записать их в manifest;
- подставить URL в CSV, если указан `URL папки медиа`.

Если `URL папки медиа` пустой, CSV всё равно создастся, но картинки и ZIP нужно будет загрузить на сайт и сопоставить отдельно.


```powershell
python .\scripts\wp_excel_to_woocommerce_csv.py --input .\input\products.xlsx --output .\output\products.csv
```
