# Quick Commands

## 1. Start a new project

```text
This project is for [goal].

Start with README.md and START_HERE.md, ask only the minimum missing questions, then make the project work and verify it before final reply.
```

## 2. Do the next task

```text
Take the next open task from TASKS.md and do it.

Explain the plan first, then implement the task, verify it, and update TASKS.md and CHANGELOG.md.
```

## 3. Check the result

```text
Review the current result against README.md, PRD.md, TASKS.md, and CHANGELOG.md.

Verify the main flow, fix blocking issues, and report the exact commands used.
```

## 4. Refactor safely

```text
Refactor the current code only if it improves readability, removes duplication, or makes the next task safer.

Do it as a separate step, verify after the refactor, and do not change behavior unless it is part of the requested task.
```
